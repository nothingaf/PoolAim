# PoolAim

Projeto Android inicial para testar uma janela flutuante sobre outros aplicativos.

## Estado atual

Esta versão inicial terá uma tela de configuração e uma sobreposição não interativa. Ela ainda **não** captura a tela do jogo, não reconhece bolas e não calcula trajetórias automaticamente.

## Gerar o APK

O workflow Android APK em GitHub Actions compila um APK de depuração. Depois de executar o workflow, baixe o artefato PoolAim-debug-apk na página da execução.
